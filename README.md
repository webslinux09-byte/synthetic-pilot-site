# Synthetic Pilot Site

Technický pilot jednoduchého statického webu. Všechny názvy, texty a zdroje
jsou syntetické a nesmí být považovány za informace o skutečném klientovi.

Repozitář je záměrně oddělený od hlavního OpenClaw workspace. Nesmí obsahovat
tokeny, cookies, autentizační soubory, Notion exporty, databázi leadů ani
skutečné kontaktní údaje.

## Lokální kontrola

Otevři `site/index.html` nebo spusť lokální statický server uvnitř adresáře
`site`.

Publikování na GitHub nebo nasazení na hosting je samostatný krok.
